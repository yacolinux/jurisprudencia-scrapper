      Portal remoto de jurisprudencia

La app de consulta trabaja primero con el archivo local en modo no destructivo. Cuando se activa la opción remota, usa este MCP para localizar resultados y detalles; compara cada uno con la caché por ID o fuente y solicita el PDF solamente si falta. El PDF se guarda ordenadamente en data/, se crea un Markdown lateral sin alterar el original y el modelo configurado en OPENCODE_MODEL lee únicamente ese Markdown.

ACCESO REMOTO

Cloudflare y navegador

El acceso HTTP directo puede recibir un challenge. Por eso el cliente admite Chromium/Xvfb y también reutilizar un Chrome externo mediante JURIS_CDP_URL=http://127.0.0.1:9222. Si el challenge no puede resolverse automáticamente, la ejecución queda informada para reintento manual.

PERSISTENCIA

Archivo local

La app de descarga conserva cada PDF en el bind mount local ./data, con carpetas por año, mes y fecha. La captura anual recorre la paginación anual y filtra las fechas localmente porque el sitio no ofrece un índice mensual confiable.
